# イジンデン Online - Web Prototype

## 起動方法
1. ZIPを展開
2. `index.html` と `app.js` と `cards.json` を同じフォルダに置く
3. ローカルのWebサーバーで開く（例: `python3 -m http.server 8000`）
4. ブラウザで `http://localhost:8000` を開く

## 収録データ
ユーザー提供の第1弾〜第6弾Excelカードリストを統合した576件。カード名、レアリティ、色、レベル、パワー、特性、ルールテキスト、遺業能力を収録。

## 現状
- カード検索・閲覧
- デッキ編集・localStorage保存
- 対戦盤面のUIテスト
- ルーム作成・参加UIモック
